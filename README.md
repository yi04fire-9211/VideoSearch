# 小燚的数据库 · 本地 AI 使用说明

用自己的 AI 查四火的歌曲、原话、连麦或直播经历。准备 **Skill** 和 **字幕档案** 两样东西。

## 第一次使用

1. 下载 `xiaoyi-archive-skill.zip`，或下载 GitHub 上的 `xiaoyi-archive` 源码文件夹，两种任选一种。支持直接安装 Skill ZIP 的工具可导入 ZIP。需要文件夹的工具请先解压，再导入含 `SKILL.md` 的 `xiaoyi-archive` 文件夹。能访问本地项目并运行 Python 的 AI，也可以从这个文件夹直接读取 `SKILL.md` 并执行脚本。
2. 下载字幕档案 ZIP，在电脑上解压一次，拿到 `xiaoyi-search-v1.sqlite3.gz`。把它放在 AI 能访问的本地文件夹里，记下完整路径。
3. 把下面这段话发给 AI，替换成你的文件路径。允许它读取该文件并运行包里的 Python 查询脚本。首次使用由脚本解压索引，之后可直接复用生成的 `xiaoyi-search-v1.sqlite3`。

> 请使用「小燚的数据库」Skill，先读取 SKILL.md。我的字幕档案在【填入 xiaoyi-search-v1.sqlite3.gz 的完整路径】。请优先使用已解压的 SQLite 索引，没有的话请用包里的 prepare 命令解压。先查「萨满 四火」，给我日期、P 数、时间戳、B 站链接和匹配依据，区分画面核对与字幕候选。如果能看到 **2026-10-27 · P7 · 10:27** 的双人连麦，就可以开始问自己的问题。接着可以试问「四火某段时间没法正常排档、唱歌和连线的时期，大概是什么时候？请按时间串联证据。」

## 录屏链接已经随包提供

搜索结果自带原片直达链接。Skill 也附了捏脸、橙子、草莓尖尖的主页和使用场景。查人或 PK 时，AI 若能打开 B 站视频，就让它回看带界面版的席位和说话画面。想剪辑时，再用草莓尖尖的清屏版对齐时间。主页的新投稿需要等档案更新，或通过浏览器另行查找。

## 如果AI 只能上传文件

同一个索引和脚本能复现本地候选。要达到同样的画面核对精度，还需要 AI 能打开录屏并看清席位或听到声音。遇到只支持普通聊天附件的工具，请在电脑上运行 Skill 安装说明里的查询命令，把查询输出的 JSON 和你的问题一起发给 AI。要核对画面时，再提供对应时间点的截图或片段。整个 SQLite 档案应保存在本地供脚本查询。
