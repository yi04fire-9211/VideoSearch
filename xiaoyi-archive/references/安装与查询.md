# 安装与查询

把 Skill 文件夹导入支持 SKILL.md 的工具，再下载并解压单独的字幕档案 ZIP，告知工具索引所在路径。命令需要 Python 3 和启用了 FTS5 trigram 的 SQLite。标准库即可运行。以下命令从 Skill 文件夹运行，路径按实际位置修改。

```sh
python3 scripts/archive.py prepare "/路径/xiaoyi-search-v1.sqlite3.gz"
python3 scripts/archive.py --db "/路径/xiaoyi-search-v1.sqlite3" search "萨满 四火"
python3 scripts/archive.py --db "/路径/xiaoyi-search-v1.sqlite3" search "姥姥" --from 2026-08-10 --to 2026-08-31 --literal
python3 scripts/archive.py --db "/路径/xiaoyi-search-v1.sqlite3" context BV1jbxG6AEqw 7 627 --radius 20
python3 scripts/archive.py --db "/路径/xiaoyi-search-v1.sqlite3" day 2026-08-22
```

`search` 默认先走匹配规则。需要核对其他关键词、歌词或单独的两字人名时，用 `--literal` 读取直接命中的字幕，并回看上下文。相似说法可分次查询。同一场的多个版本有不同 P 和秒数，分别保留来源。用 `context` 查看附近字幕，或用 `--radius 180` 扩大到三分钟。用 `day` 列出该日视频及已有字幕的 P。

如果 AI 只能阅读文件，由用户在本地运行上述命令，把查询输出保存成 JSON 后上传给 AI。例如在命令末尾加 `> results.json`。不同 AI 的 Skill 导入、脚本执行和本地文件权限有所区别，豆包等第三方平台的 ZIP 导入尚未验证。浏览器和视频访问能力取决于所使用的工具及录屏可见性。
